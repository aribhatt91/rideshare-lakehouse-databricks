# RideShare Lakehouse & Real-Time Operations Platform

## Business problem

> Build a scalable data platform for a ride-sharing company that processes historical trip data in batch and continuously ingests new trip events to provide near-real-time operational analytics.
>
> Imagine you are working at an Uber-like company.

The company receives:

- historical trip records
- driver information
- rider information
- location information
- payment information
- continuously arriving trip events

The analytics team wants to answer:

> "What is happening in our transportation network right now?"

Operations wants:

- trips per minute
- driver utilization
- cancellation rate
- average trip duration
- surge demand
- pickup hotspots
- abnormal trip patterns

Finance wants:

- revenue
- commissions
- driver payouts

Data scientists want:

- demand forecasting datasets
- driver behavior features
- rider behavior features

Your job is to build the data platform underneath all of this.
